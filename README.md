# Worklog Summary Card Component

An Angular 16+ recruitment assignment implementing a responsive worklog summary card component using Tailwind CSS for an ERP system.

## Features

- ✅ Angular 16+ standalone component
- ✅ Pure Tailwind CSS styling (no UI libraries)
- ✅ Fully responsive design (mobile + desktop)
- ✅ Role-based styling (admin, manager, employee)
- ✅ Conditional "View Details" button
- ✅ Graceful avatar handling with fallbacks
- ✅ Semantic and accessible HTML
- ✅ Dark mode support
- ✅ @apply directives for clean code
- ✅ Preview wrapper with demo cards

## How to Run

```bash
# Install dependencies
npm install

# Start development server
ng serve

# Open browser to http://localhost:4200
